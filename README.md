## The five risks

1. Shadow AI: unvetted tools and plugins handling work data
2. Data Leakage: sensitive data sent to third-party servers, baked into future models
3. Hallucination Laundering: unverified AI output submitted as factual work
4. Prompt Injection: direct overrides and indirect attacks hidden in retrieved data
5. Unauthorized Agentic AI: unmonitored agents and lingering "zombie" agents with live credentials

Outright bans drive AI use underground, so govern instead.
