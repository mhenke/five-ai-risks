# 🕵️‍♂️ 15-Minute Discussion Guide: Uncovering AI Security Risks

Facilitator guide for
[Five AI Risks That Can Get You Fired—And How to Avoid Them](https://www.youtube.com/watch?v=1m55T8xST9s).
Pairs with the [compressed slide deck](./Five-AI-Risks-That-Can-End-Your-Career-compressed.pptx).

### 1. Opening: Stepping onto the Scene (0:00 – 2:00)

- **Detective Framing**: Set the stage like a noir investigator stepping onto a rain-slicked street. Most AI career disasters aren't committed with malicious intent; they happen when well-meaning people cut corners thinking they're just being productive.
- **Discussion Hook**: *"Raise your hand if you've used a personal AI tool or quick browser extension this week just to get work done faster."*
- **Core Premise**: Using AI without proper governance or human verification is where careers go sideways.

---

### 2. Case File Breakdown: Examining the 5 Suspects (2:00 – 11:00)

#### Suspect #1: Shadow AI (The Unvetted Accomplice)

- **Talking Point**: Employees adopting unapproved tools — such as personal accounts or browser plugins — outside IT visibility.
- **The Evidence**: **1 in 5 organizations** report experiencing a data breach caused by Shadow AI. Simply banning tools backfires because employees move to personal devices, leaving IT completely blind to risks.

#### Suspect #2: Data Leakage (The Evaporating Secret)

- **Talking Point**: Pasting proprietary code or sensitive customer records into unapproved third-party tools.
- **The Evidence**: Data sent across third-party servers can be used to train future model iterations, making it impossible to claw back. A leak like this leads straight to a career-ending meeting with the CISO.

#### Suspect #3: Hallucination Laundering (The False Alibi)

- **Talking Point**: Taking unverified, plausible-sounding AI output ("slop") and copying it straight into formal work deliverables.
- **The Evidence**: Whether it's legal filings packed with fake case citations or executives making major decisions based on unverified stats, the AI's name isn't on the document — yours is.

#### Suspect #4: Prompt Injection (The Hidden Manipulator)

- **Talking Point**: Malicious inputs designed to override an AI system's system prompt instructions.
- **The Evidence**: While direct prompt injections target chat windows, **indirect prompt injection** hides inside retrieved emails, web pages, or documents to manipulate autonomous workflows secretly.

#### Suspect #5: Unauthorized Agentic AI (The Zombie Rogue)

- **Talking Point**: Autonomous agents given system access to read/write databases, call APIs, or send messages without human oversight.
- **The Evidence**: When projects end, forgotten **"zombie AI agents"** remain authenticated with active API keys, creating unmonitored backdoor vulnerabilities in company infrastructure.

---

### 3. The Detective's Rulebook: Governance & Verification (11:00 – 13:00)

- **Talking Point**: Strict bans only push risks further into the shadows.
- **Core Solution**: Robust governance frameworks that establish explicit approved tool lists, clear data boundaries, and mandatory human-in-the-loop verification before publishing.

---

### 4. Closing & Team Discussion (13:00 – 15:00)

- **Wrap-Up Question for the Group**: *"Which of these five risks represents our team's biggest blind spot today, and what verification step should we implement immediately?"*
